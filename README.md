# Doces da Lê

Site desenvolvido para a **Doces da Lê**, uma pequena marca de doces artesanais feitos sob encomenda.

O projeto foi criado com o objetivo de proporcionar uma presença digital simples, bonita e acessível para o negócio, permitindo que clientes conheçam os produtos disponíveis e entrem em contato de forma rápida para realizar encomendas.

**Site:** https://doces-gourmetls.vercel.app/

---

## Sobre o projeto

A proposta foi desenvolver uma **vitrine digital responsiva** para apresentar os doces da marca de forma visual e organizada.

Como os produtos são preparados sob encomenda e os valores podem variar de acordo com quantidade e personalização, o site prioriza a apresentação dos produtos e direciona o cliente para contato para consultar valores e realizar pedidos.

O design foi pensado para transmitir uma identidade delicada, artesanal e acolhedora, combinando com a proposta da marca.

---

## Funcionalidades

* Catálogo visual de doces
* Layout responsivo para celulares, tablets e computadores
* Contato facilitado para realização de encomendas
* Apresentação dos produtos através de imagens
* Seção sobre a história da Doces da Lê
* Identidade visual personalizada
* Navegação simples e intuitiva
* Site publicado e disponível online

---

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Vercel para deploy e hospedagem
* Git e GitHub para versionamento do projeto

---

## Objetivo

Além de criar uma presença digital para a Doces da Lê, este projeto teve como objetivo desenvolver uma solução simples para uma necessidade real de um pequeno negócio.

A ideia foi transformar um catálogo tradicional em uma experiência online onde potenciais clientes conseguem conhecer os produtos antes mesmo de entrar em contato.

---

## Responsividade

O site foi desenvolvido pensando em diferentes tamanhos de tela, principalmente dispositivos móveis, já que grande parte dos clientes acessa links de pequenos negócios diretamente pelo celular.

## Executando localmente

Clone o repositório:

```bash
git clone https://github.com/beatxz/doces-gourmetls.git
```

Entre na pasta do projeto:

```bash
cd doces-gourmetls
```

Depois, abra o arquivo `index.html` no navegador.
